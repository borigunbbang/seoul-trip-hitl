# 데이터 출처

데모와 제출은 `data/snapshot/`의 스냅샷으로 실행한다. 이 파일이 없으면 앱은 `tests/fixtures/`의 시험용 데이터를 쓴다.

수집일: **2026-11-09** (`config.REFERENCE_DATE`도 이 날짜로 고정해, 실행 날짜와 상관없이 경과일 계산이 같다)

| 파일 | 내용 | 출처 |
|---|---|---|
| `manual/seed.json` | 수집할 장소 41곳 (관광지 20, 음식점 18, 숙소 3) | 직접 고름. 음식점은 카카오 장소 검색("○○ 맛집", 음식점 분류) 상위 결과에서 점심 식사가 가능한 곳 |
| `snapshot/places.json` | 좌표·주소 + 영업 정보 | 좌표·주소: **카카오 장소 검색 API**. 영업 상태·요일별 영업시간·휴무일·공지·별점·후기 수·최근 후기 날짜: **카카오맵 장소 페이지를 사람이 보듯 하나씩 열어 옮겨 적음** (`manual/place_details.json`) |
| `snapshot/segments.json` | 구간 320개 | 700m 초과: **카카오 대중교통 경로 API** (255회 호출). 700m 이하: 직선거리로 도보 시간 계산. 1.5km 이하는 도보도 대안으로 추가 |
| `overrides.json` | 기준 시연용으로 일부러 바꾼 값 7개 | 아래 표 |

## 알아 둘 한계

- **구글 Places를 쓰지 않았다.** 영업 정보는 API가 아니라 사람이 확인한 값이다. 실시간 조회 모드(`LiveProvider`)는 만들지 않았다.
- **막차 시각이 없다.** 카카오 경로 API가 첫차·막차를 주지 않아 모든 구간의 `last_departure`가 비어 있다. 기준 1의 '막차 이후'는 덮어쓰기 1건으로만 시연한다.
- **최근 후기 날짜**는 카카오맵 후기의 사진 목록에서 가장 최근 날짜를 썼다. 글만 있는 후기가 더 최근일 수 있다(예: 잘빠진메밀, 명동대성당).
- 종묘는 평일(월·수·목·금)에 시간제 관람(해설사 동반)만 있어 그 요일의 영업시간을 비워 두었다. 그래서 평일 종묘 방문은 기준 3(운영 정보 없음)으로 멈춘다. 실제 정보이고 덮어쓰기가 아니다.
- 무교동북어국집에는 실제로 "직원 병가로 인한 임시휴무 공지(매주 월요일)"가 있어 공지로 넣었다. 방문하면 기준 2로 멈춘다.

## 기준 시연용 덮어쓰기 (`overrides.json`)

실제 데이터만으로는 기준에 걸리는 날이 생긴다는 보장이 없어서 일부 값을 바꿨다. 바꾼 항목은 원래 값을 함께 저장하고,
화면의 멈춘 이유와 지도 정보창에 **"※시연용으로 바꾼 값"**으로 표시된다. **아래 내용은 실제 가게·장소의 사실이 아니다.**

| 대상 | 바꾼 값 | 시연하는 것 |
|---|---|---|
| 거울못식당 | 최근 후기 → 2026-06-15 (실제 2026-09-30) | 기준 2: 최근 리뷰 없음 |
| 잘빠진메밀 서촌점 | 영업 상태 → 폐업 (실제 영업 중) | 자동 수정: 폐업 음식점 교체 |
| 창덕궁 | 11/21 특별 운영 09:00~13:00 추가 (실제 없음) | 기준 3: 특별 운영일 |
| 동대문디자인플라자 | 마지막 확인 → 2026-09-01 | 기준 4: 낡은 장소 정보 |
| 숙소(명동역) ↔ 광장시장 | 추천 경로 막차 21:00 추가 | 기준 1: 막차 이후 |
| 남산골한옥마을 ↔ N서울타워 | 버스 01B 하나만 남김 (실제로는 도보·01A도 가능) | 기준 1: 대안 없음 |
| 북촌한옥마을 ↔ 창덕궁 | 마지막 확인 → 2026-08-20 | 기준 4: 낡은 구간 정보 |

## 다시 수집하기

```bash
.venv/bin/python scripts/collect.py places     # 카카오 REST 키 필요
.venv/bin/python scripts/collect.py segments   # 하루 무료 1,000건 안에서. 받은 구간은 data/raw/에 저장돼 건너뜀
.venv/bin/python scripts/collect.py build
```
`manual/place_details.json`(영업 정보)은 자동으로 갱신되지 않는다. 다시 확인하려면 카카오맵 장소 페이지(`place_url`)를 열어 고친다.
